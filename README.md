# AI Study Helper

AI Study Helper is a web app that helps students study different topics using AI.

## Features

- Enter a study topic
- Choose Summary
- Choose Quiz
- Choose Detailed Notes
- Choose Mind Map
- Select difficulty level
- Generate study material using AI

## Difficulty Levels

- Beginner
- Intermediate
- Advanced

## Technologies Used

- Python
- Streamlit
- Google Gemini AI
